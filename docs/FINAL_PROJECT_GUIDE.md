# BI E-Commerce Multichannel - Final Project Guide

This guide is the complete and professional runbook for executing the project end-to-end.
It includes multiple execution methods (local/manual, Docker MySQL, Docker PostgreSQL, Podman), validation checks, and expected outputs.

## 1) Scope and Outcomes

This project delivers:
- Synthetic e-commerce data generation.
- Dimensional warehouse setup (star schema).
- ETL orchestration with Pentaho PDI.
- OLAP analysis with Mondrian/Saiku.
- Data mining workflows:
  - RFM segmentation.
  - Churn prediction.
  - Association rules / cross-selling.

Primary output locations:
- Raw data: `data/raw/`
- Analytics outputs: `results/`
- ETL assets: `etl/`
- OLAP assets: `olap/`

## 2) Prerequisites

Minimum:
- Python 3.10+
- Java 8+ (for Pentaho/Mondrian tooling)
- One database option:
  - MySQL 8+ (recommended), or
  - PostgreSQL 12+

Optional:
- Docker Desktop or Podman Desktop
- Pentaho Data Integration (Spoon)
- Saiku Analytics
- Power BI / Pentaho Report Designer

Install Python dependencies:

```bash
pip install -r requirements.txt
```

## 3) Quick Start (Fastest Path)

If your objective is to validate data generation + data mining in minutes:

```bash
python scripts/generate_data.py
python scripts/rfm_analysis.py
python scripts/churn_prediction.py
python scripts/association_rules.py
```

Expected files in `results/`:
- `rfm_analysis_results.csv`
- `rfm_segment_summary.csv`
- `churn_predictions.csv`
- `churn_feature_importance.csv`
- Association rules outputs generated by `association_rules.py`

## 4) Method A - Full Local/Manual Run (Recommended for learning)

### Step A1 - Generate Source Data

```bash
python scripts/generate_data.py
```

Check that these files exist in `data/raw/`:
- `customers.csv`
- `products.csv`
- `channels.csv`
- `regions.csv`
- `orders.csv`
- `returns.csv`
- `feedback.csv`

### Step A2 - Create Warehouse Schema

MySQL:

```bash
mysql -u root -p < sql/setup_database.sql
```

PostgreSQL:
- Use the same logical schema from `sql/setup_database.sql` with PostgreSQL-compatible syntax.

### Step A3 - Run ETL (Pentaho)

Open `etl/Master_Job.kjb` in Spoon and execute.

Core transformations loaded by the project:
- `ETL_0_Load_Time.ktr`
- `ETL_1_Load_Customers.ktr`
- `ETL_2_Load_Products.ktr`
- `ETL_3_Load_Channels.ktr`
- `ETL_4_Load_Regions.ktr`
- `ETL_5_Load_Delivery.ktr`
- `ETL_6_Load_Orders.ktr`
- `ETL_7_Load_Returns.ktr`
- `ETL_8_Load_Feedback.ktr`

### Step A4 - Validate OLAP

- Confirm `olap/ecommerce_catalog.xml` is deployed.
- Validate Mondrian connection settings in `olap/mondrian.properties`.
- Run MDX checks from `docs/MDX_QUERIES.md`.

### Step A5 - Run Data Mining

```bash
python scripts/rfm_analysis.py
python scripts/churn_prediction.py
python scripts/association_rules.py
```

## 5) Method B - Docker Compose (MySQL)

Use this for a reproducible full-stack environment.

```bash
docker compose up -d
```

Then run analytics scripts from the workspace:

```bash
python scripts/generate_data.py
python scripts/rfm_analysis.py
python scripts/churn_prediction.py
python scripts/association_rules.py
```

Stop environment:

```bash
docker compose down
```

## 6) Method C - Docker Compose (PostgreSQL)

Start with PostgreSQL profile and matching env config.

```bash
docker compose --profile postgres up -d
```

Run the same Python analysis flow:

```bash
python scripts/rfm_analysis.py
python scripts/churn_prediction.py
```

Stop environment:

```bash
docker compose --profile postgres down
```

## 8) Validation Checklist

After a full run, validate:

1. Data generation:
   - All 7 CSV files exist in `data/raw/`.
2. Warehouse:
   - Fact and dimension tables are populated.
3. ETL:
   - `Master_Job.kjb` finishes without critical errors.
4. OLAP:
   - MDX queries execute successfully.
5. Data mining:
   - Required output files exist in `results/`.

Optional runtime checks:

```bash
python scripts/test_environment.py
python scripts/test_db_connection.py
```

## 9) Standard Project Workflow

Use this sequence for repeatable execution:

1. Regenerate source data.
2. Rebuild/refresh warehouse schema as needed.
3. Execute ETL master job.
4. Validate OLAP queries.
5. Execute data mining scripts.
6. Consume outputs in BI/reporting tools.
